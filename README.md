# mini-inventory

Sistema de gestão de estoque desenvolvido em Java para praticar conceitos de Programação Orientada a Objetos.
Conceitos aplicados

Herança e classes abstratas:
Modificadores de acesso (protected, super)
Polimorfismo e casting
Formatação de valores monetários com NumberFormat e Locale
ArrayList e for-each

Funcionalidades:

Cadastro de produtos eletrônicos e perecíveis
Cálculo automático do valor total por produto
Desconto automático de 10% em produtos perecíveis
Relatório de estoque com valor total geral

Tecnologias:

Java 21
VS Code
